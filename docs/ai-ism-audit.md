# Copy AIism Audit - 2026-08-11

## Scope

Reviewed the visitor-facing app summaries, static crawler fallback, static profile, LLM-readable files, project descriptions, assistant briefing cards, and the supplied resume copy. Internal policy documents were changed only where they directly feed employer-facing assistant answers.

This is a language-quality review, not a claim that any phrase was generated by AI. A phrase is flagged when it is vague, repeated, label-heavy, or substitutes a broad claim for concrete evidence.

## Findings And Resolution

### High: repeated abstract identity labels

The site repeatedly described James as "nontraditional, systems-oriented" and used phrases such as "practical reasoning" and "learning velocity" as a primary explanation of value. The words are not inaccurate, but repetition made the copy sound defensive and abstract.

Resolution: replaced public summaries and assistant briefing cards with the current resume framing: AI product and UX engineer, healthcare and enterprise-systems background, and product work that exposes requirements, evidence, tradeoffs, and human review.

### Medium: generic AI value language

"AI as a practical force multiplier" appeared in public pages and machine-readable text. It says little about the actual work.

Resolution: replaced it with concrete behavior: using AI to prototype, test, and explain workflow decisions, with visible constraints and verification.

### Medium: source-grounded used as a marketing adjective

"Source-grounded" is meaningful when it describes the assistant's approved-source retrieval boundary. It becomes vague when used as a general substitute for a product description.

Resolution: retained it for the assistant architecture and documented retrieval behavior. Replaced promotional uses with direct descriptions of the relevant tool or workflow.

### Low: generic subtitle

"An AI-powered living resume" is broad branding rather than a detailed value proposition. It was explicitly selected for the James AI subtitle, so it remains. The spelling is corrected to "AI-powered."

### Low: supplied resume transition framing

The supplied resume calls James a "career-changing AI product builder." This is not an AIism, but it foregrounds the career transition before the product and UX evidence. The source DOCX was not edited because it was supplied as the resume authority. Consider changing it in a future resume-only revision if the desired first impression is current capability rather than transition context.

## Terms Intentionally Retained

- "Human-in-the-loop," "inspectable memory," and "source grounding" are retained where they name an implemented interaction or technical boundary.
- "Evidence," "tradeoffs," and "constraints" are retained because the public projects document those exact behaviors.
- Project boundaries such as "synthetic data," "local-only," and "simulated" are retained to prevent overstatement.

## Validation Standard

The refresh must preserve factual alignment across the resume PDF, source corpus, project grid, static HTML profile, LLM-readable files, retrieval tests, and responsive browser checks.
